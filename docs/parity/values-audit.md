## Shared Svelte contracts

The integration owner accepted the following direction before dependent implementation:

- Preserve existing `createAnimate`, `createScroll`, `createInView`, raw `motionValue`, `springValue`, `mapValue`, `transformValue`, `stagger`, and `motionStore` behavior and import paths.
- Add familiar `use*` factories called during component setup or an owned Svelte effect. They own their subscriptions, frame work, and values; raw engine factories retain explicit caller ownership. Component setup runs once, so there is no React hook-order restriction.
- Return engine `MotionValue<T>` instances directly from value helpers. A caller-owned input is never destroyed by a derived helper. `motionStore(value)` remains the Svelte store bridge.
- Accept getters for reactive source identities, DOM targets, and option objects. Ordinary arguments are captured values. Callback bodies may read current Svelte state; callback identity is not guessed from function arity.
- Return readonly `.current` objects for reactive booleans. Returning a primitive snapshot cannot remain reactive across Svelte module boundaries. Svelte's native `MediaQuery` can represent reduced motion, but Astra's helper supplies the familiar surface and the shared lifecycle.
- `useAnimate()` returns `[scope, animate]`. The scope supplies `.attach` for `{@attach scope.attach}`, a reactive `.current`, and supports the general DOM engine subjects and sequence overloads. Existing `createAnimate` restrictions remain separately documented.
- A single optional activity-context reader pauses owned effects while an activity is hidden without destroying retained MotionValues. The integration owner connects this to activity lifecycle; standalone use defaults to active.
- SSR creates deterministic values, installs no DOM listeners or frame loops, and does not read browser globals. Initial page visibility is `true`; in-view initial state is configurable; reduced-motion preference is unknown (`null`) until measured. Animation playback itself requires a browser.

## Investigated discrepancies and implemented decisions

1. **Reduced motion:** the article promises live updates. Both 13.4.3 and 13.4.4 initialize a state value from shared preference and never subscribe the React component to changes. Astra implements the documented live behavior and retains the raw policy helper separately. Svelte `.current` is the only adaptation needed.
2. **Disabled frame callback:** the page-visibility article calls `useAnimationFrame(undefined)` when hidden. The implementation and declaration require a callback and invoke it without a guard. Astra accepts `undefined` and exposes reactive enablement, with no queued frame while disabled.
3. **In-view initial state:** upstream `inView` suppresses an initial outside notification. Its React hook also skips the observer when `initial:true` and `once:true`. Existing Astra tests establish the documented first-measurement meaning and must not be regressed to copy these defects. Astra resets `once` when the target element is replaced; explicitly document this element-scoped choice.
4. **Value destruction:** overview prose says hook-created MotionValues are automatically destroyed. `useMotionValue` contains no destroy effect. Some derived hooks unsubscribe their inputs, while `useVelocity` leaves already-scheduled polling uncancelled. Astra's owned values destroy their resources and cancel scheduled work while preserving borrowed sources.
5. **Template literals:** upstream `if (value)` drops literal numeric zero. The managed Astra tag preserves zero and string interpolation. MotionValue objects containing zero happen to work upstream because the object is truthy.
6. **Dynamic derived dependencies:** the vanilla `transformValue` explicitly requires a pure function without conditionals and collects inputs only initially; the React transform hook recollects on render. Svelte has no repeated component render call. Astra tracks Svelte getters and recollects MotionValue dependencies whenever computation runs, removing old subscriptions. A plain alias would be incorrect.
7. **Spring source replacement and units:** upstream `useFollowValue` depends on serialized options and the output, not the source. `attachFollow` also appends the output unit to an already-unit-bearing source before `skipInitialAnimation` calls `jump`. A direct Node probe against DOM 13.4.2 produced `20pxpx` from a `10px` source changed to `20px`; source is byte-identical in 13.4.4. The managed wrapper avoids this defect and verifies source changes; raw exports remain upstream-compatible.
8. **Spring defaults:** inspected generator defaults are stiffness 100, damping 10, mass 1, bounce 0.3, with the follower layer overriding restDelta to 0.001 and restSpeed to 0.01. Transition prose says stiffness 1 and bounce 0.25. Astra reuses and documents actual helper defaults, recording the discrepancy without changing the shared engine.
9. **String velocity:** the overview says string values return zero, but the implementation uses `parseFloat`, so numeric unit strings have velocity. A direct probe using `setWithVelocity('0px','20px',10)` returned 2000. Preserve this useful engine behavior and document units accurately; non-numeric strings/colors return zero.
10. **Scroll acceleration and retention:** React useScroll adds `.accelerate` metadata; raw mapValue and existing createScroll progress do not. The engine timeline cache is a strong Map with no eviction in the inspected source. New helper acceleration uses scoped timeline ownership, and the component renderer consumes it. Merely returning four MotionValues does not establish this performance contract.
11. **Scroll option reactivity:** upstream restarts subscriptions only for ref identity and serialized offsets; changing other options alone may not reconnect. Astra's option getter supports all documented option changes, with cleanup before rebinding.
12. **useAnimate compatibility:** upstream scopes selector lookup but allows explicit external DOM subjects and general values/objects. Existing createAnimate intentionally enforces exclusive node ownership and an authored-transform restriction. Astra preserves that documented contract and its tests, and exposes the general hook separately. B8–B18 verify subjects, lifecycle, Activity and timeline composition; the packed consumer exercises integration with components.

13. **Spring duration units:** documented transitions use seconds, but the follower engine passes `duration` straight to its millisecond generator. A direct probe with duration 0.5 produced a 10ms generator (minimum clamp), while duration 500 produced 500ms. The integration owner approved seconds for managed `useSpring`; its wrapper converts seconds to milliseconds. Existing raw `springValue` remains unchanged.
14. **SVG geometry writes:** `svgEffect` reads initial geometry from attributes but writes CSS-supported properties through styles. The first Chromium check passed numeric `r`; Firefox/WebKit exposed an upstream 13.4.4 defect: `addStyleValue` serializes numeric `r`, `rx`, `ry`, `cx`, `cy` without units, and these browsers reject them. A direct `animate(circle, { r: 17 })` reproduction left attribute `r="10"`, empty inline style and computed `10px`, even after another frame; `CSS.supports('r', '17')` returned false. Astra's scoped hybrid helper uses public `svgSubjectEffect.state()` / `MotionValueState.set()` to correct numeric serialization to px while retaining the same effect values, store, sequence timing and handoff identity. Existing motion-component values are left with their own renderer. The mini helper normalizes those numeric CSS keyframes before WAAPI, with no hybrid import. Explicit units remain intact; `attrR: 18` continues to write attribute `r="18"`. Regressions cover arrays, replacements, interruption, element collections, all five geometry properties and unchanged ordinary object values. No engine prototype or global value-type table is changed.
15. **External timeline teardown:** `GroupAnimation.attachTimeline` invokes child cleanup and child.stop; an AsyncMotionValueAnimation child invokes its observer disposer twice. Managed useAnimate makes observer cleanup idempotent, releases it during hidden Activity, and reconnects it on reveal.
16. **Native replay state:** NativeAnimation.play renews its finished promise but retains its finished-time marker, exposing `state: finished` during replay. The wrapper clears that marker through a public seek to the unchanged replay time and resumes playback. Mini complete also handles infinite iterations and speed zero through the same WAAPI timing adaptation already used by Astra's general completion compatibility layer.
17. **Reactive accelerated scrolling:** native progress timelines return percentage-based computed duration. Switching to a custom-offset observer without restoring a time-based timeline produces non-finite WAAPI currentTime. Astra owns a native timeline per binding, restores document-timeline duration before fallback/suspension, and retains the same animation across container/offset/activity changes. A browser test covers the rendered style, not only the source value.

18. **Shared scroll tracking lifetime:** the inspected 13.4.4 `scrollInfo` implementation keeps `dimensionCheckProcesses` per container. Enabling content tracking creates a keep-alive `frame.read` callback. Disposing an individual handler returns early while any container handlers remain; only final-handler cleanup cancels the dimension callback. Astra releases every subscription it owns, but another live subscriber can retain this shared engine work after the original requesting owner disables tracking or unmounts. This matches upstream and must not be described as per-hook dimension-poll isolation. No upstream global map/prototype is patched. A dedicated multi-owner quantitative browser probe remains useful release evidence; the lifecycle behavior is established by inspected source, and B7 establishes the single-owner content/teardown path.

19. **Arc subjects and sequences:** the 13.4.4 hybrid effect animator does not dispatch its documented MotionPath option. The integrated scoped helper now resolves DOM/SVG subjects, shares the existing style/SVG effect values, and invokes the public path contract. Awaitable grouped controls retain ownership of the positional driver. For sequences, Astra delegates ordinary paint/callback tracks and numeric position timing to the upstream compiler, samples exact public arc generators from that shared clock, and preserves labels, relative positions, seeks and overlap handoff.
