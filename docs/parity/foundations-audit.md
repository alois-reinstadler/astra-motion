## Error and cleanup policy

Invalid targets and unsupported configuration are surfaced at their responsible
boundary: engine resolver errors for animation values; explicit diagnostics for
missing lazy features; Svelte error boundaries for rejected feature loading;
constraint validation for drag; and asynchronous transition handle rejection for
view update failures. Destruction cancels owned work and subscriptions. Externally
supplied MotionValues and the application's DOM state are not destroyed merely
because a consumer subscription ends.

SSR state is per component/request, not a process-global animation tree. No public
runtime entry imports React. The optional navigation entry is the only entry that
requires SvelteKit. Exact installed declaration and module-graph results are in
[package results](PACKAGE-RESULTS.md); source tests alone do not qualify the tarball.
