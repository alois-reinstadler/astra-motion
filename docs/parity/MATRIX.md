2026-09-28. Baseline: **Motion, framer-motion and motion-dom 13.4.4**;

## Source discrepancies and release gates

`dragElastic` is documented as 0.5 but 13.4.4 source uses 0.35; source defaults
are the compatibility baseline. Direction lock uses >10px, y first on ties.
Legacy controls.set reverses labels (first label wins), unlike target array
resolution (last label wins). View source types admit transform aliases and
transitionEnd that its native replacement loop does not implement; examples use
real CSS properties, and Astra rejects transitionEnd explicitly. The View source
handles only the first suffixed root layer; Astra coordinates all supplied roots.
Activity alpha's private implementation is unavailable, so only published
behavior and the approved Svelte lifecycle contract can be qualified.

Release gates still open: full browser matrix, meaningful new interaction checks,
strict source/packed consumer including SSR/hydration/lifecycle, bundle isolation,
production rendering of all 34 pages and canonical examples, fresh adversarial review,
polish review, merge/push, CI, Pages and deployed browser verification. No unresolved
functional gap may be relabeled full parity.

Additional confirmed source discrepancies: a nonempty raw transform takes
precedence over decomposed transforms in Motion's style builder. Removing its
animation target returns to the initial/base transform, so changing from raw to
independent transforms requires explicitly resetting the raw transform. Astra
components preserve that observable precedence. Native legacy bindings
retain their stricter raw/decomposed ownership diagnostic. arc() uses a quadratic
control point: strength1 produces a midpoint offset of half the travel distance,
not the full distance stated in the article; displacements below20px use a straight
projection. Focused regressions preserve both observed contracts; final matrix evidence remains required.
