# Motion parity contract and evidence

Current consolidation is tracked in the [main ledger](../releases/2026-10-11-consolidation.md).
Qualification and deployment claims apply only to the revisions named in their records.
See [migration](../migration.md), [text motion](../text-motion.md) and
[tilt](../tilt.md) for current public contracts.

Reference baseline: **2026-09-27 UTC**, **Motion, framer-motion and motion-dom
13.4.4**, **motion-utils 13.3.0**, upstream commit
`636e725fc71315ca91ff196eb09685017e2fe0c8`. Astra targets Svelte **5.57.0** and
SvelteKit **2.70.3**. Official reference URLs appear in the matrix below.

This matrix describes implemented behavior and explicit Svelte adaptations alongside
its regression coverage. It is not qualification of a future release artifact.
Run the [release checklist](../release-checklist.md) against the exact candidate
commit and archive. Physical iPhone performance remains unqualified.
See [shared Svelte contracts](CONTRACTS.md) for lifecycle and ownership boundaries.

## Source discrepancies and release gates

`dragElastic` is documented as 0.5 but 13.4.4 source uses 0.35; source defaults
are the compatibility baseline. Direction lock uses >10px, y first on ties.
Legacy controls.set reverses labels (first label wins), unlike target array
resolution (last label wins). View source types admit transform aliases and
transitionEnd that its native replacement loop does not implement; examples use
real CSS properties, and Astra rejects transitionEnd explicitly. The View source
handles only the first suffixed root layer; Astra coordinates all supplied roots.
Activity alpha's private implementation is unavailable, so only published
behavior and the approved Svelte lifecycle contract can be qualified.

Release qualification must cover runtime behavior, strict source/packed consumers,
bundle isolation, documentation destinations and deployed behavior for the candidate
revision. No unresolved functional gap may be relabeled full parity.

Additional confirmed source discrepancies: a nonempty raw transform takes
precedence over decomposed transforms in Motion's style builder. Removing its
animation target returns to the initial/base transform, so changing from raw to
independent transforms requires explicitly resetting the raw transform. Astra
components and native bindings preserve that observable precedence. Diagnostics
identify raw transforms that mask independent targets; there is no legacy binding
ownership mode. arc() uses a quadratic
control point: strength1 produces a midpoint offset of half the travel distance,
not the full distance stated in the article; displacements below20px use a straight
projection. Focused regressions preserve both observed contracts; integrated matrix and focused correction evidence are recorded.
