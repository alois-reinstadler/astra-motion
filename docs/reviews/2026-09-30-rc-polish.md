# RC distortion audit and two refinement rounds

This pass starts from `4f60939` and preserves the existing unfinished layout,
site-release and glyph-regression changes. It does not publish or qualify a new
registry artifact.

## Findings and changes

- The homepage's resizing surfaces need separate position-only boundaries for
  their numbers and labels. The live example supplies them; the short copyable
  excerpt now explicitly makes its `strong` transformable without relying on
  omitted flex CSS.
- Ordinary inline text and `display: contents` cannot render layout transforms.
  The development diagnostic now covers initial registration and retained
  attachment updates, including measurement-only hosts that become animated.
  It preserves authored display styles, permits replaced inline elements and
  blockified flex/grid items, and deduplicates per element.
- Frame-level glyph checks cover the homepage, player, expanding note,
  coordinated panels, list/grid reorder, editing desk and publishing queue at
  desktop and phone widths, including rapid reversals. The note additionally
  proves its detail appeared, exited, and released the captured card size.
  Existing contact-sheet tests cover shared image/title proportions.
- Release labels and installation archive names use shared package metadata.
  The guide checker now loads transpiled content from a temporary module tree,
  preserving the metadata import instead of failing on relative imports from a
  data URL. Complete copyable examples still undergo Svelte checking.
- Component tests use a separate dependency optimizer cache from the live site.
  The website component fixture's initial hydration wait uses the normal locator
  timeout; tighter assertions remain on subsequent animation interactions.

## Independent refinement

Round one reviewed layout correction, the selected examples and their regressions
in an isolated snapshot. It identified the retained-registration diagnostic gap
and missing note-exit completion assertions; both are repaired and tested.

Round two reviewed the integrated changes and the clipboard API findings in a
second isolated snapshot. It found no further blocking source defect. Refactoring
was limited to the reusable diagnostic and release metadata; a wider rewrite was
not justified. Both reviewers were read-only; the main agent owns verification.
