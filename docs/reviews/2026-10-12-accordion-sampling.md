# Accordion phase sampling correction

The final WebKit source run in `source-webkit-qualified.log` reported two accordion failures: one intermediate closing frame at 240px where the test required more than two, and one intermediate reversal frame where it required more than one. All sampled 0.5px geometry assertions passed. A 200ms transition sampled by a separate requestAnimationFrame loop does not guarantee that many intermediate paints, particularly with WebKit's roughly 30Hz frame cadence under suite load.

Only `accordion-preview.svelte.spec.ts` changes. The real example, its 200ms duration, and runtime remain unchanged. Exact phase tests now sample five explicit phases of the actual animation. Entry uses Motion's existing AsyncMotionValueAnimation pause/time/play controls. Retained exit and reversal use the actual native Animation with playbackRate zero; its playState remains running so Svelte's tick loop stays alive. Restoring the original rate lets Svelte finish retention naturally. The original intermediate counts (>2 opening/closing, >1 reversal), 0.5px geometry tolerance, retained-node identity, focus, ARIA state, and final cleanup assertions remain.

An additional independent natural-playback case changes no clock, duration, easing or playback rate. It observes rendered height changes, asserts intermediate opening, reverses on an intermediate exit, asserts intermediate reentry, and completes another exit with intermediate height and eventual removal. Trigger/text geometry and focus are checked as well. MotionValue change notifications queue a microtask after the actual render, avoiding a competing RAF observer's ordering gap.

Focused validation: four tests pass in each of Chromium, Firefox and WebKit (12 passes). ESLint and Prettier checks pass. Negative controls restore the original grid behavior with an inline `align-content: normal` on the example stage in the test only; all four tests fail in each engine on geometry, preserving their ability to detect the original defect. The temporary override is removed from the committed test.

Evidence is outside the worktree at `/workspace/releases/astra-motion/layout-runtime-feedback-2026-10-12/accordion-sampling/`: the three `*-final.log` files and three `*-negative-control.log` files. Earlier investigation logs remain, including incorrect clock-selection attempts; they are not qualification results. The original complete-suite failure log is unchanged. Complete final-tree source qualification remains the consolidator's responsibility.
