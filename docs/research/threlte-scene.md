Review date: 2026-09-29. Experiment: `experiments/threlte-scene/`. Core library files and dependencies are unchanged. The port installs Astra’s exact RC archive, SHA256 `8c001390e0406e5e628873bcd5f4f2a8a026e372aa2037f20ccc6578fe88515f`, with Threlte 8.6.1, Three.js 0.186.1, and Svelte 5.57.0.

## What was actually ported

| Original mechanism                                           | Threlte / Astra implementation                                                              | Difference                                                                                                                                                        |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Drei ScrollControls, three pages                             | Native document scroll; Astra `useScroll`, spring and derived pose                          | Preserves 0–1 progress and three chapters; native links, text and keyboard scrolling remain ordinary Svelte markup. Spring smoothing differs from Drei’s damping. |
| Camera trigonometric orbit with `offset = 1 - scroll.offset` | Same three equations in `scene-path.mjs`; direct PerspectiveCamera updates                  | Adds bounded cursor translation and slight model yaw. Tests compare source equations at five positions.                                                           |
| `Take 001` time follows half the clip duration in reverse    | Three AnimationMixer absolute time follows `clip.duration * (1 - progress) / 2`             | Source has extra action-time damping; this port applies the already spring-smoothed Astra pose directly.                                                          |
| Model scale 0.02, position [0, 2.5, 0], cast/receive shadows | Same model, transform and shadow flags                                                      | Geometry and textures are unchanged.                                                                                                                              |
| Pink spotlight, fog, procedural sky                          | Hemisphere, ambient and two directional lights on a transparent canvas                      | Deliberate lighting and presentation change; not claimed pixel-identical. Actual rendered lighting remains unverified here.                                       |
| React useFrame continuous evaluation                         | Borrowed Astra MotionValue subscription applies the scene pose and calls Threlte invalidate | Uses Threlte’s existing on-demand rendering. No new engine or adapter needed.                                                                                     |

The composition adds a warm editorial layout, three story chapters, responsive type, local fonts, native animated progress and ornament bindings, visible rendering status, keyboard/touch view buttons and an explicit Still view. Astra is substantively responsible for camera, clip, cursor and DOM animation; it is not merely an import around an unrelated render loop.

[Drei ScrollControls](https://drei.docs.pmnd.rs/controls/scroll-controls) supplies scroll ranges and damping in the source ecosystem. [Threlte’s existing render modes](https://threlte.xyz/docs/learn/basics/render-modes/) and [useThrelte context](https://threlte.xyz/docs/reference/core/use-threlte/) supply the renderer, camera and invalidation needed in Svelte. Three’s [keyframe animation example](https://threejs.org/examples/webgl_animation_keyframes.html) also demonstrates the model. No evidence here supports a need for a vgpu integration or a general Threlte adapter.

## Ownership and accessibility

The component setup owns its Astra values; the scene bridge borrows them and unsubscribes without destroying them. A private GLTF load owns its decoder, mixer, geometries, textures and materials. Fetch is abortable, late decode completion is guarded, cleanup disposes private resources and restores its previously selected camera. Threlte owns the canvas lifecycle. No shared loader cache is disposed.

The scene has no permanent frame callback. Its derived quiet pose stops depending on scroll/cursor values; reduced-motion users receive a fixed camera and clip. Native text, links, chapter progress and keyboard navigation continue to work. OS reduced-motion wiring is source-reviewed; the same Still view branch was exercised in the browser. No claim of physical touch testing or OS preference emulation is made.

The visible caption distinguishes `WebGL2 · live 3D`, loading, explicit scene errors, a paused canvas, and `Reference image · WebGL2 unavailable`. The static image is not a result of the port renderer. The GPU-only pause/reload path is implemented but not executed on this machine.

## Recommendation and remaining device check

Use this as an isolated, reviewable app example of Astra values driving an existing Threlte scene. The strongest demonstrated benefit is composition: one scroll/cursor model drives authored GLTF animation, camera movement and ordinary Svelte UI while the renderer remains Threlte’s responsibility. Existing ecosystem capabilities cover the rendering layer. Maintenance consists of the small value bridge, explicit private-resource cleanup, model attribution, and pinned example dependencies; no general adapter is justified by this scene alone.

The port requires a final GPU-capable device inspection before claiming its live lighting/composition and canvas lifecycle are qualified. Check all chapters, cursor and keyboard framing, OS reduced motion, repeated Pause/Load 3D, console/network, and a physical touch device. No GPU acceleration, frame-rate improvement or cross-device performance claim is made. The scene’s 2.57 MB model and approximately 290 KB gzip JavaScript are real costs; reducing initial Three loading or texture/model budgets would be a separate optimization supported by measurements.
